# 线下色卡采集工具集

本项目是一个本地桌面软件，用于线下色卡图片识别、重命名、截图和模板生成；当前四个首页入口均已完成。

了解本工具怎样为皮革系统准备色卡扫描图和主图，先读[与皮革项目的衔接](LEATHER_INTEGRATION.md)。

现有功能以1.0.0为基线；主图尺寸与EXIF标记为1.1.0，中文安装向导和组件精简为1.2.0。版本只在 `pyproject.toml` 的 `project.version` 中维护：源码运行直接读取该文件，安装包读取随包携带的同一文件，普通 Python 安装读取包版本。之后修改版本并重新打包，图片中的 `tool_version` 自动跟随，无需修改写入代码。

## 当前范围

- 首页四个入口均已实现并可用。
- “叠贴转平贴模板生成”进入可用页面。
- “色卡扫描图改名”进入可用页面。
- “主图截图及名称更改”进入可用页面。
- “SPU名称生成不干胶模板”进入可用页面。
- 第一个功能包含图片选择、云端视觉识别、识别结果确认、分组校验、Word 模板生成。叠贴转平贴已统一走完整原图云端识别，云端失败时保留可编辑结果供人工修正。
- 图片改名功能会识别图片左上角名称，将原图复制到目标目录并改名。
- 主图截图功能会先在本地做标尺健康检测，只有检测通过的图片才调用云端视觉模型识别完整构图中任意位置的白底标签名称；随后按标尺交点生成带上方和左侧标尺的 `10×10`、`15×15`、`5×5`、`5×10` 或 `10×5 cm` 主图，通过本地浏览器复核名称与图片，再按最终名称保存。标尺检测失败时不会回退到中心裁剪。
- SPU 不干胶功能会读取 Excel 第一工作表指定列，写入固定 Word 不干胶模板。
- 色卡标注工具（Review App）是一个本地 Web 应用，用于给色卡图片画框标注并导出 YOLO 训练数据集。

## 第一功能使用流程

1. 进入“叠贴转平贴模板生成”。
2. 确认内置模板为“转平贴底纸模板.docx”。
3. 输入输出 Word 名称，选择保存目录。
4. 选择 `.jpg/.jpeg/.png` 图片。
5. 点击“开始识别”。
6. 在识别结果表中修正组名、序号、色号列表。
7. 点击“生成 Word”。

云端配置不完整时会先提示补齐 Base URL、API Key 和 Model；单张云端识别失败时，软件会保留可编辑行，并默认使用图片文件名作为组名，用户可手动修正后继续生成。

## 识别方案说明

项目早期优先尝试彻底本地化：使用 YOLO 检测横版和竖版色卡的名称区域（name_area）与色号区域（code_area），再交给 RapidOCR 识别。这个方向可以离线运行，但实际维护成本很高：需要分别训练横版、竖版模型，OCR 对裁剪边界、背景线条、旋转标记和连读数字都比较敏感，而且本地 OCR/推理不适合高并发批量处理。

当前方案是云端视觉模型识别。软件会在底部“识别设置”中配置 `Base URL`、`API Key`、`Model` 和云端并发数。并发数支持 `1-10`，结果会按原始图片顺序回填，不会因为并发完成顺序不同而串行错位。

横版和竖版现在都直接发送完整原图到云端，不再做 YOLO 裁剪，也不再回退本地 YOLO/OCR。历史实测在 `qwen3.6-flash` 这类模型上，单张图片成本约为 `0.3 分`人民币量级，具体以接口返回 token 和模型价格为准。每批识别结束后，软件会弹窗显示输入/输出 token、预估费用、实际耗时、API 耗时合计和并发倍率，并在用户数据目录 `%LOCALAPPDATA%/线下色卡采集工具集/logs/` 写入详细日志。

移除 YOLO 推理的 2026-10-02 决策、成本估算和保留范围见：`docs/decisions/2026-10-02-remove-yolo-runtime.md`。历史本地方案复盘见：`docs/local-only-recognition-complexity.md`。

## 图片改名与截图

### 色卡扫描图改名

1. 进入“色卡扫描图改名”。
2. 选择“色卡改名后扫描图片保存的地址”。
3. 选择需要改名的 `.jpg/.jpeg/.png` 色卡扫描图。
4. 点击“确认”。

软件会识别每张图片左上角的数字或文字作为文件名，将整张原图复制到目标目录，不重新压缩。遇到重名时自动追加 `-2`、`-3`。

### 主图截图及名称更改

1. 进入“主图截图及名称更改”。
2. 选择截图尺寸：`10×10`、`15×15`、`5×5`、`5×10` 或 `10×5 cm`。
3. 选择截图及改名后图片保存的地址。
4. 选择对应要截图及改名的 `.jpg/.jpeg/.png` 图片。
5. 在“识别设置”中可调整主图专用的标尺检测搜索范围（默认 `20%`）和云端并发数（默认 `3`，范围 `2–10`）；并发设置同时用于首次识别和失败重试，与叠贴识别独立。
6. 点击“确认”。软件先本地检测标尺，检测通过后才调用云端识别名称。
7. 云端识别完成后会提示打开本地浏览器复核页（回环地址 `http://127.0.0.1:<随机端口>/`）；页面顶部明确显示当前裁剪尺寸（`10×10`、`15×15`、`5×5`、`5×10` 或 `10×5 cm`）。每张卡片都显示来源文件名，点击图片可打开核对窗口，同时查看完整原图和对应裁剪图，并支持放大、上一张/下一张、修改完整名称、取消保存。全部核对后点击“确认保存”。也可以在桌面页面取消“识别后打开浏览器复核”后直接保存。

软件会先识别上方和左侧标尺并检查刻度支撑度，以标尺交点为截图起点裁出指定尺寸，再按复核后的名称保存。尺寸优先按图片 DPI 换算；图片没有 DPI 时按 `300 DPI` 处理。JPEG 保存沿用源图量化表与色度采样，PNG 保持 PNG 格式。标尺健康检测失败时会给出原因和建议搜索范围，不会生成中心裁剪文件，也不会为失败图片调用云端。

最终带标尺图在保存时自动写入 EXIF `UserComment`，包含 `marker`、`tool_version`、`width_cm`、`height_cm`、`origin_x`、`origin_y`。原点是摆正后输出图中的整数像素坐标；写标记与裁剪保存一次完成，不额外压缩 JPEG。复核后的改名和文件复制保留标记。

作者于 2026-10-28 确认：上游物理扫描流程目前固定，通常产出 JPEG。PNG 支持仅覆盖 PNG 格式主图输入，预计很少使用；上游流程变化后再调整判断。请将处理后的原文件交给管理后台，传输或编辑造成信息丢失时需重新取得原文件。

## SPU 名称生成不干胶模板

1. 进入“SPU名称生成不干胶模板”。
2. 点击 `+` 选择要转换的 `.xlsx` 文件。
3. 输入 Excel 起始单元格的行和列，例如行 `2`、列 `2` 表示 `B2`。
4. 查看固定内置模板“8144-不干胶贴模板.docx”。模板只能查看，不能在软件里替换。
5. 输入转换后的 Word 名称，选择保存地址。
6. 点击“确定”。

软件只读取 Excel 第一个工作表，从起始单元格所在列往下读取连续非空内容，遇到空单元格停止。内置模板每页为 `24 行 * 6 列`，一页写满后自动复制第一页表格继续写入。

## 色卡标注工具（Review App）

色卡标注工具是一个本地 Web 应用，用于给色卡扫描图片手动标注 YOLO 训练数据。

启动：

```powershell
.\scripts\start_review_app.ps1
```

或直接运行：

```powershell
.\.venv\Scripts\python -m color_card_toolkit.review_app
```

默认监听 `http://127.0.0.1:8765/`，浏览器打开即可使用。

功能：

- 浏览 `datasets/raw_images/` 下的原始色卡图片。
- 对图片绘制 name_area 和 code_area 标注框。
- 保存标注到 `datasets/manual_annotations/annotations.json`。
- 导出 YOLO 格式数据集到 `datasets/manual_annotations/exports/`。

可通过 `--raw-root`、`--annotation-path`、`--export-root` 参数自定义路径。
