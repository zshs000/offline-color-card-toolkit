# 功能 2：主图截图及名称更改需求说明

## 1. 当前状态

该功能已实现。

## 2. 功能目标

根据用户选择的带标尺主图，先在本地完成标尺健康检测，再通过云端视觉模型识别图片任意位置的白底标签名称。识别结果在本地浏览器复核页中确认或修改后，按标尺交点和用户选择的尺寸截取图片，并将截取后的图片按最终名称保存。

## 3. 页面需求

用户点击首页“主图截图及名称更改”后进入该功能页面。

页面包含：

1. 截图尺寸选择
   - `10cm * 10cm`
   - `15cm * 15cm`
2. 输出保存目录选择
   - 选择截图及改名后图片保存的地址。
3. 图片选择
   - 选择要截图及改名的图片。
4. 识别设置
   - 与“叠贴转平贴模板生成”共用 `Base URL`、`API Key` 和 `Model`。
   - 主图处理固定使用 2 并发。
   - 主图专用“标尺检测搜索范围 (%)”，默认 `20%`。
   - 可选择识别后是否打开浏览器复核页。

## 4. 处理规则

点击确认后，软件需要：

1. 读取用户选择的图片。
2. 使用主图专用搜索范围先做本地标尺健康检测，不调用云端。
3. 对健康检测通过的图片，将完整构图等比例缩小到最长边不超过 2048 像素，通过云端视觉模型读取任意位置白底标签中的名称，忽略标尺数字。
4. 自动检测上方和左侧标尺的交点，根据图片 DPI 和用户选择的尺寸生成临时复核图。
5. 自动打开本地回环地址的浏览器复核页，顶部显示当前裁剪尺寸（`10cm * 10cm` 或 `15cm * 15cm`）。页面按三列展示图片和来源文件名；点击任意图片后打开核对窗口，同时展示完整原图和对应裁剪图，支持放大、上一张/下一张、修改完整名称、取消某张图片；也可在桌面页面关闭浏览器复核。
6. 用户确认后，将复核图复制到目标目录并按最终名称保存。
7. 如果识别名称为空，使用原文件名并提示用户。
8. 如果目标文件名重复，自动保存为 `名称-2.jpg`、`名称-3.jpg`。
9. 如果标尺健康检测失败，不生成中心裁剪结果，也不调用云端；界面显示原因和建议搜索范围。

## 5. 尺寸换算规则

- 优先读取图片自带 DPI 进行厘米到像素的换算。
- 图片没有 DPI 或 DPI 无效时，默认按 `300 DPI` 换算。
- `10cm * 10cm` 保留左侧标尺 `0-10` 和上方标尺 `15-5`。
- `15cm * 15cm` 保留左侧标尺 `0-15` 和上方标尺 `15-0`。
- 输出包含上方、左侧标尺带，因此输出像素宽高大于纯皮料区域本身。

## 6. 图片质量要求

- 截取后的图片必须尽量保持原图信息。
- 不应主动压缩导致图片质量明显下降。
- JPEG 输出使用最高质量保存。
- PNG 输出保持 PNG 格式。

## 7. 验收标准

- 用户可以从首页进入“主图截图及名称更改”页面。
- 用户可以选择 `10cm * 10cm` 或 `15cm * 15cm`。
- 用户可以选择输出目录和多张图片。
- 点击确认后，目标目录生成按白底标签名称命名的截图图片，标签位置不受限制。
- 截图结果带有上方和左侧对应范围的标尺，不包含范围外的名称标签。
- 重名图片不会覆盖已有文件。
